# Big Blue Welding Design Reference

## Design Inspiration

The design should feel inspired by a premium industrial manufacturing website.

Do not copy the sample website directly.

The visual style should be:
- Dark
- Industrial
- Premium
- Clean
- Strong
- Structured
- Trustworthy
- Modern
- Local service business focused
- Built around getting quote requests and phone calls

## Layout Style

Use a strong one-page homepage layout.

The page should feel like a high-end industrial service website, not a cheap local business template.

Use:
- Large hero section
- Big confident headline
- Dark background
- Steel-blue glow accents
- Safety-orange call-to-action buttons
- Service capability cards
- Strong section spacing
- Large image/card blocks
- Industrial grid patterns
- Subtle border lines
- Slight metallic feel
- Clean typography
- Clear contact buttons

## Hero Section Direction

The hero should have:
- Dark navy / black background
- Large bold headline on the left
- Supporting paragraph under it
- Trust chips under the paragraph
- Two clear buttons
- Large industrial image placeholder on the right
- Small detail labels, like:
  - Since 1985
  - Calgary & Area
  - Mobile Welding
  - 24-Hour Answering Service

The hero should feel strong and premium, but not flashy.

## Image Direction

Use placeholder/default image blocks for now.

Do not use random stock photos yet.

Create visual placeholders using:
- CSS gradients
- dark metal texture feel
- subtle grid lines
- welding glow
- framed card borders
- labels like "Welding Project Image"
- no broken images

The placeholders should look intentional, not empty.

## Color Palette

Use CSS variables.

Suggested colors:
- Background: #071018
- Dark section: #0b1520
- Card: #101d2a
- Border: rgba(255,255,255,0.12)
- Text: #f4f7fb
- Muted text: #a9b5c4
- Steel blue: #3ea7ff
- Deep blue: #0f4c81
- Safety orange: #ff8a1f
- Soft glow: rgba(62,167,255,0.22)

## Typography

Use system fonts or Google Fonts.

Preferred:
- Headings: Archivo, Sora, Oswald, or system sans-serif
- Body: Inter or system sans-serif

Headings should be bold, clear, and industrial.

## Design Rules

Do:
- Make it look premium
- Make the phone number easy to find
- Make the CTA buttons obvious
- Make the service cards clean
- Make mobile layout excellent
- Keep the site fast
- Use real business info

Do not:
- Copy the sample site exactly
- Use fake reviews
- Use fake certifications
- Use fake project numbers
- Use cheesy sparks everywhere
- Use random neon effects
- Make it look like a tech startup
- Overload the page with text
